# Fundamental architecture — path forward

> **Demo file.** Delete with its folder.

The grand plan's depth doc: where the analysis accumulates while the folder-note stays a thin map. Split out
because a folder-note that grows sections stops being scannable, and because this is the part that gets long.

What belongs here as the plan firms up:

- **Anatomy of the problem** — what is actually coupled to what, traced from source rather than remembered.
  Long-lived; the kind of thing worth re-reading instead of re-tracing.
- **Edit inventory** — the enumerated set of changes the plan implies, so its size is a number and not a mood.
- **Sequenced roadmap** — the order forced by dependencies, and *why* each step must precede the next.
- **Exit criteria** — how you will know it is done, decided now, while you are honest.

What does **not** belong here: per-workstream status, PR numbers, "what's next". A grand plan's serving
workstreams each own their frontier; restating it here is how two copies start disagreeing.
